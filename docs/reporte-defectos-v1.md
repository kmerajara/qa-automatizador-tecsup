## 3. Información requerida por defecto

- Fecha real de detección.
- Entorno y navegador.
- Precondiciones.
- Pasos para reproducir.
- Resultado esperado.
- Resultado obtenido.
- Severidad y prioridad justificadas.
- Estado de seguimiento.
- Evidencia o enlace a Jira.

## 4. Criterios de registro

Los identificadores DEF-001 a DEF-005 son espacios reservados y no representan defectos encontrados. Solo se reportarán incidencias verificadas mediante ejecución real de pruebas.

## 5. Conclusión

El reporte se actualizará conforme se ejecuten los casos y se disponga de evidencias verificables.
